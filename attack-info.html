Attack Simulator

Someone has obtained John's email address and password from a criminal forum. They are about to try using them to access his bank account.

You are going to play the attacker. The password is correct, so the only thing stopping you from accessing his money is the second security check on his account.

What you will do

  1. Choose a second security check. You can select a code sent by text message, a code from an authentication app, or an approval request sent to John's phone.
  2. Sign in with the stolen password. The login information will already be displayed and ready to use.
  3. Try to pass the second security check. You can view John's phone during the demonstration, although a real attacker would not have access to it.
  4. See what happens. After every attempt, you will learn whether the login succeeded and why.

Try the simulation with every authentication method to compare how each one protects the account.

This is a safe practice page. JU Bank is not a real bank, John is not a real person, and nothing you enter is stored or sent anywhere.
